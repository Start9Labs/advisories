# Firefly III: dashboard summary boxes still show values with Transaction Hiding enabled — fixed in 6.7.2

## Symptom

With Transaction Hiding (privacy mode) turned on, transaction values are hidden throughout the dashboard except in the four coloured summary boxes along the top, which continue to display real values.

## Affects

All users who enable Transaction Hiding on the dashboard, on versions through v6.7.1.

## Cause

The summary box widgets were not covered by the privacy mode value-masking logic applied elsewhere on the dashboard.

## Remedy

Update to Firefly III v6.7.2 or later, where the summary boxes respect Transaction Hiding along with the rest of the dashboard.

## Notes

Confirmed by a maintainer and marked fixed, targeted for the v6.7.2 milestone; no release date given.
