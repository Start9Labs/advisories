# Firefly III: tags disappear when editing a transaction — fix coming in 6.7.2

## Symptom

When editing a transaction that has tags, the tags field appears empty. The tags are still there — viewing the transaction (the "show" view, not edit) displays them correctly.

## Affects

Anyone on Firefly III 6.7.1 editing a transaction that has one or more tags. This is a display bug only in the edit form; the tags are not lost.

## Cause

A display bug in the transaction edit view introduced in 6.7.1; the show view is unaffected.

## Remedy

This is fixed for the next release, 6.7.2. Until then, do not remove or re-add tags while editing a transaction based on the empty field — the tags are still stored and remain visible in the transaction's "show" view.

## Do not

- Do not re-enter or delete tags to "fix" the empty field while editing — they are already saved and doing so risks duplicating or losing them.
