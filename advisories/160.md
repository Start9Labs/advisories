# Open WebUI: deleting a direct connection in Settings > Connections comes back after reloading

## Symptom

A personal direct connection is deleted in Settings > Connections, and it disappears from the list. But after reloading the page, the deleted connection is listed again — unless the Save button in that pane was also clicked right after deleting it.

## Affects

Anyone using Direct Connections who deletes one and reloads (or navigates away and back) without separately clicking Save in that pane. Adding, editing, or switching a direct connection off/on already save immediately and are not affected.

## Cause

The delete handler removed the connection from the page's local state but did not save it, unlike adding, editing, or switching, which already trigger a save.

## Remedy

This is fixed upstream, but the fix has not yet reached a released version — it will be available once a release containing it reaches StartOS. Until then, after deleting a direct connection, click the Save button in the Connections pane to make the deletion stick; without doing so, the deleted connection returns on reload.

## Notes

Fix merged upstream (open-webui/open-webui#31384); no release yet names it, so no version can be given.
