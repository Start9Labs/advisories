# Re-download WireGuard configs after updating StartTunnel to 1.2.0+

## Symptom

None visible — everything that worked keeps working. The device just doesn't get the new DNS features.

## Affects

Any device using a WireGuard config generated before StartTunnel 1.2.0.

## Cause

WireGuard configs gained DNS entries in StartTunnel 1.2.0. Configs issued before then don't have them.

## Remedy

Re-download or copy the config from StartTunnel for each device and update it there. On StartOS: System → Gateways → the StartTunnel gateway's overflow menu → Update Config, then paste or upload the new config.

## Notes

Known since 2026-07-24.
