# Open WebUI: adding a second model to a chat turns off Web Search, Image Generation and Code Interpreter

## Symptom

A chat is comparing two or more models, each of which has Web Search, Image Generation or Code Interpreter enabled as a Default Feature. Adding another model to the comparison turns those feature toggles off, and the comparison then runs without them — even though every selected model has them on by default.

## Affects

Anyone using multi-model comparison (adding a second or later model to a chat) where the models involved have default features configured. Single-model chats are not affected.

## Cause

Changing the model selection clears the feature toggles and reapplies model defaults, but the defaults were only ever reapplied for a single model rather than for all models in the comparison.

## Remedy

This is fixed upstream, but the fix has not shipped in a Start9 package release yet — it will be available once a release containing it reaches StartOS. Until then, after adding models to a comparison, manually re-enable any default features (Web Search, Image Generation, Code Interpreter) that were turned off.

## Notes

The fix also corrects a related mismatch where the Web Search toggle shown on screen could disagree with what was actually sent in the request when switching models.
