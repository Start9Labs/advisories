# Open WebUI fails to install with `Error: sh terminated with signal SIGKILL` on slower disks

## Symptom

Installing Open WebUI fails and rolls back. The error reported is `Error: sh terminated with signal SIGKILL`, occurring during the `seedModelCache` step, roughly 30 seconds after the install's seed overlay mounts (and unmounts shortly after failing). This happens even with other services stopped and after a reboot.

## Affects

Anyone installing Open WebUI on hardware whose disk cannot copy the ~265 MB model cache in under 30 seconds — reported on a Server Pure. Does not depend on memory pressure or other running services.

## Cause

`seedModelCache` copies the image's model cache onto the volume with a copy command that has no timeout set, so a 30-second default applies and kills the copy before it finishes on slower disks. Every install then fails and rolls back.

## Remedy

The fix has merged (removing the 30 s limit on this copy) but has not yet reached a version available to install. Once a release containing it is available, installing Open WebUI on affected hardware will no longer fail this way.

## Notes

The fix is recorded as open-webui 0.11.4:1, currently on the alpha registry only; it is not yet available on the main Start9 Registry.
