# Open WebUI: leaderboard Activity chart shows "No activity data" for models with a slash in their id

## Symptom

On the Leaderboard's Activity chart, a model whose id contains a slash (for example an Ollama model pulled from Hugging Face) always shows "No activity data", on every time range, even though the model has ratings. Models whose id has no slash show their chart normally.

## Affects

Anyone viewing the Leaderboard Activity chart for a model whose id contains a slash. Models without a slash in their id are unaffected.

## Cause

The Activity chart's history route took the model id as a plain path segment, which cannot contain a slash, so lookups for slash-containing ids failed silently and showed no data.

## Remedy

This is fixed upstream, but the fix has not shipped in a Start9 Registry release yet. There is no workaround; the chart will start showing data for these models once a release containing the fix reaches StartOS.

## Notes

Fix merged upstream in open-webui/open-webui#30456 (closes open-webui/open-webui#30455). No Start9 Registry release is stated to contain it yet.
