# Immich thumbnail generation crashes on short iPhone video clips

## Symptom

Thumbnail generation fails for short (roughly 1–4 second) videos recorded on iPhone, with server logs showing:

```
ERROR [Microservices:{"id":"<asset-id>"}] Unable to run job handler (AssetGenerateThumbnails): Error: ffmpeg was killed with signal SIGSEGV
```

The affected videos are short HEVC `.MOV` clips (`yuvj420p` pixel format, `smpte170m`/`smpte432`/`bt709` color metadata) with frame-crop side data. Log output shows ffmpeg's filter chain ending up with zero usable frames (`0 frames in, 0 frames out`) before the crash. The asset uploads fine and appears in the library, but never gets a thumbnail.

## Affects

Anyone uploading short iPhone-recorded video clips to Immich. Confirmed on Immich 3.1.0 and 3.2.0. Not tied to a particular install size or config — it depends only on the video's length and encoding, which is common with iPhone Live Photo-style short clips.

## Cause

Immich's ffmpeg filter chain for thumbnail generation (`fps=12,thumbnail=12,...,trim=end_frame=2,reverse`) can end up with an empty frame set for very short clips; the subsequent `reverse` filter then triggers an out-of-bounds condition that crashes ffmpeg (jellyfin-ffmpeg build) with SIGSEGV rather than failing gracefully.

## Remedy

There is no released fix yet. A proposed fix (prepending `setpts=N` to the filter chain, from immich-app/immich#25079) has been independently verified by multiple reporters to prevent the crash and produce a valid thumbnail, but it was closed unmerged and is not in any shipped version, including the current 3.2.1. Affected assets will keep failing thumbnail generation until an upstream fix ships; there is no setting or update to apply today.

## Notes

- The failing asset itself is otherwise fine — only thumbnail generation for it fails; it does not affect the rest of the library.
- Support should watch for immich-app/immich to merge and release a fix (the `setpts=N` change or equivalent) and update this advisory once a version ships it.
