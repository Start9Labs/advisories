# Update to 0.4.0.1 fails with "Filesystem I/O Error: No current.rootfs"

## Symptom

The update to 0.4.0.1 fails with `Filesystem I/O Error: No current.rootfs`.

## Affects

Only servers that reached 0.4.0 by over-the-air update from 0.3.5.1. A fresh 0.4.0 install is unaffected.

## Cause

An over-the-air update from 0.3.5.1 to 0.4.0 leaves current.rootfs unset, which the next over-the-air update requires.

## Remedy

SSH into the server, run the command below, then retry the update.

```
sudo ln -rsf "$(sudo ls -t1 /media/startos/images/*.rootfs | head -n1)" /media/startos/config/current.rootfs
```

## Notes

Known since 2026-07-27.
