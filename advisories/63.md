# Gitea: update to 1.26.3 for security fixes — private repo data exposure and SSRF via migration

## Symptom

No visible symptom. These are security issues rather than something a user would notice: a Personal Access Token without repo scope could read private repository commit data through the RSS/Atom feed endpoints, repository migration could be made to reach internal network addresses via an attacker-controlled HTTP redirect, and revoked users could still see private issue/PR metadata leaked through the notification API.

## Affects

All Gitea instances prior to 1.26.3. No configuration or feature needs to be enabled to be exposed.

## Cause

Three separate issues fixed together: missing repository token scope enforcement on RSS/Atom feeds, HTTP redirects followed during repository migration clones, and notification subjects not redacted after repository access is revoked.

## Remedy

Update Gitea to 1.26.3 or later.
