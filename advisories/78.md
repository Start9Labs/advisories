# Firefly III 6.7.1: Categories column missing from Transactions list — fix coming in 6.7.2

## Symptom

After updating to Firefly III 6.7.1, the Categories column is gone from the Transactions pages (both expenses and revenue), making it hard to see at a glance whether transactions are properly categorized.

## Affects

Everyone running Firefly III 6.7.1, the version currently shipped by StartOS. Not a setting — this is a change to the default Transactions list view.

## Cause

An unintentional design change in 6.7.1 dropped the Categories column from the transaction list views.

## Remedy

This is a known issue, confirmed by a Firefly III maintainer, who has said the column will return. The fix is targeted for the next release, 6.7.2, which StartOS does not yet ship. There is no setting to restore the column in the meantime — categories are still stored correctly and visible on individual transactions, just not shown as a column in the list.

## Notes

Not a data-loss issue — category assignments are unaffected, only the list-view column is missing.
