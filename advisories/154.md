# Gitea: migrating a repository from Gitea or Forgejo hangs forever on issues with many comments

## Symptom

Migrating a repository into Gitea from another Gitea or Forgejo instance never finishes. The migration hangs indefinitely with no error, specifically getting stuck on any issue that has at least `MAX_RESPONSE_ITEMS` comments.

## Affects

Anyone migrating a repository from a Gitea or Forgejo source into their Gitea instance, where at least one issue in the source repository has a comment count at or above the `MAX_RESPONSE_ITEMS` setting (default 50). Migrations from other source types, or of repositories whose issues all have fewer comments, are unaffected.

## Cause

The source instance's `GET /repos/{owner}/{repo}/issues/{index}/comments` endpoint ignores the `page` and `limit` parameters and always returns every comment. Gitea's downloader pages through comments and only stops when it receives a page shorter than the limit, so with an endpoint that ignores paging, it never sees a short page and loops forever.

## Remedy

This is fixed upstream (milestone 1.27.4), but the fix has not shipped in any released version yet. There is no released version and no version to update to yet. Once a Gitea release containing this fix reaches StartOS, updating to it will resolve the hang.

## Notes

No workaround is known for a migration that is currently stuck on such an issue; it will need to be retried once the fix is available.
