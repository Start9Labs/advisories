# Mattermost: fresh login with no teams loops forever on the team-select screen

## Symptom

After logging in for the first time, a user who is not a member of any team gets stuck: the screen flashes or reloads repeatedly instead of settling on a usable team-selection view. The server and API stay healthy (`/api/v4/system/ping` returns 200), and reloading the browser, clearing site data, or restarting the container does not fix it. In the browser console or desktop logs this shows up as a repeating WebSocket close/reconnect cycle (`websocket closed manually`).

## Affects

Any Mattermost instance where a logged-in user belongs to zero teams — most commonly a freshly installed instance right after the admin account is created, before any team exists or the user has been added to one. Users who already belong to at least one team are unaffected.

## Cause

The web client redirects to `/select_team` whenever `teams.length === 0`, which unmounts the main app component and closes the WebSocket connection. The client then reconnects, remounts, sees zero teams again, and repeats the cycle indefinitely.

## Remedy

There is no fixed version yet. Create a team and add the affected user to it — once the user belongs to at least one team, the loop stops and the normal team screen loads. This can be done from a Mattermost admin account, or via the `mmctl` CLI:

```
mmctl team create <team> --display-name "<Display Name>"
mmctl team users add <team> <username>
```

## Notes

Reported against Mattermost 11.6.0 and reproduced independently on 11.7.0, both shipped versions on StartOS. Affects the web client and the desktop app equally, so it is not a StartOS-specific packaging issue.
