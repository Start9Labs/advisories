# Jellyfin 12.0: new content in nested library folders doesn't show up correctly — fixed in 12.1

## Symptom

After upgrading to Jellyfin 12.0, new content added to nested library folders (e.g. a "Shows" library with subfolders like Sports/My Baseball team, Sports/My Football team) does not appear under its correct subfolder. Instead, all new content across a top-level folder's subfolders gets grouped into the first subfolder found for that top-level folder. Files remain in their correct location on disk; only the database's view of the folder structure is affected.

## Affects

Jellyfin 12.0 users with nested folder structures inside a library (e.g. content organized in subfolders under top-level category folders).

## Cause

A regression in how Jellyfin 12.0 builds its database view of nested library folders, introduced in the 12.0 release.

## Remedy

This is fixed in Jellyfin 12.1. Update to 12.1 or later when it is available.

## Notes

The underlying files are not moved or lost — this is a database/display issue, not data loss. Trickplay generation and other file-based processing continue to work normally even while the folder view is affected.
