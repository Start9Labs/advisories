# Home Assistant: temperature sensors intermittently switch from °C to °F after a restart even though Unit system stays Metric

## Symptom

Settings → System → Home information still shows Unit system as Metric (°C), but some temperature sensors start displaying in Fahrenheit — usually noticed after Home Assistant restarts or after it has been running for a few hours. Toggling Unit system to US Customary and back to Metric fixes the affected sensors immediately, but the problem returns after the next restart. History/statistics for the affected sensors show a discontinuity (e.g. jumping from ~72 to ~22) at the point the unit flipped, even though nothing about the sensor changed. Developer Tools → Statistics does not flag any issue for these entities.

## Affects

Any Home Assistant instance with Unit system set to Metric and Country set to US (or otherwise resolving to a US locale). Only temperature sensors that have no explicit `unit_of_measurement` override in their entity registry entry are affected; sensors where a unit override has been set manually keep displaying in °C across restarts. Not specific to any one integration — reported across Shelly, ZHA and mobile_app sensors on the same system, with two identical ZHA devices behaving differently depending on whether one has an override.

## Cause

Not confirmed. A reporter's diagnostics show `.storage/core.config` (`unit_system_v2: "metric"`) is not being changed or rewritten by the restart, so the setting itself is not reverting. Instead, `.storage/core.entity_registry` is being rewritten during startup, and entities without an explicit unit override pick up Fahrenheit as their default instead of the configured Metric system — plausibly derived from the `country` field rather than `unit_system_v2`. No maintainer fix has been proposed yet; the issue is still tagged needs-more-information upstream.

## Remedy

No fix is available yet. As a workaround, set an explicit unit override on each affected temperature entity (its unit_of_measurement in the entity settings) — entities with an override have been confirmed to survive restarts in °C. This has to be repeated for each affected entity, and does not protect newly added entities, which will still default to °F until they too are given an override.

## Do not

- Re-toggling Unit system between Metric and US Customary only fixes it until the next restart; it is not a real fix.

## Notes

- Long-term statistics recorded while an entity was showing °F are stored in that unit; because °C and °F convert automatically, Home Assistant's statistics repair flow does not detect or flag this, so affected history will show a step discontinuity that has to be understood as a unit-label artifact, not a real temperature change.
- Confirmed on core-2026.9.2 and reproduced on core-2026.9.3; still open and unresolved upstream as of this writing.
