# Open WebUI: saving Settings > Interface resets your default model

## Symptom

A user sets a personal default model (via **Set as default** in the model selector), then opens **Settings > Interface** and saves it — even without changing anything there. Afterward, new chats no longer open with the chosen default model: instead they open with the admin's first default model, or if the personal default was a list of several models, it gets cut down to just the first one.

## Affects

Any user who has set a personal default model (single or multiple) and later saves the Settings > Interface tab for any reason. Users who never touch Settings > Interface, or who only ever set their default through **Set as default**, are unaffected.

## Cause

The Interface tab no longer shows a default-model setting, but it still silently loaded and re-saved a leftover default-model value whenever the tab was saved, overwriting the real default set via **Set as default**.

## Remedy

This is fixed upstream, but the fix has not been released yet — it will be available once a release containing it reaches StartOS. Until then, avoid saving Settings > Interface after setting a personal default model, and re-apply **Set as default** if the default model reverts.

## Do not

- Do not tell the user to just pick the model again in the chat — the wrong default returns the next time Settings > Interface is saved, since the underlying setting is not fixed.
