# Bitwarden clients updated after 24 July fail against older Vaultwarden

## Symptom

The browser extension fails to load. On mobile and desktop the client signs in and reports a successful sync but the vault appears empty, while new items can still be added. The Vaultwarden web vault is unaffected and still shows everything, which is what makes it look like a client-side problem.

## Affects

Every official Bitwarden client — browser extension, desktop, Android, iOS, and CLI — against any Vaultwarden below the current release. This is not specific to one client. A user reporting it on one is hitting it on all of them.

## Cause

Bitwarden client releases from 24 July 2026 onward are stricter about the JSON the server returns. Older Vaultwarden builds send data those clients reject.

## Remedy

Update Vaultwarden to the latest version. That version requires StartOS 0.4.0-beta.10 or newer, so a server on 0.4.0-beta.9 or earlier must update StartOS first — the Vaultwarden update will not appear in the marketplace until it does. Vault data is never at risk here; it stays intact on the server throughout, and no client-side account deletion is ever part of the fix.

## Notes

Known since 2026-07-25.
