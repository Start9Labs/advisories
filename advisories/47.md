# Home Assistant: Spotify reauthentication crashes with `KeyError: 'id'` — fixed in 2026.9.3

## Symptom

Reauthenticating the Spotify integration fails before the confirmation dialog appears, with the log showing `KeyError: 'id'`. The only apparent workaround is deleting and recreating the integration entry.

## Affects

Home Assistant instances with the Spotify integration that go through reauthentication (e.g. after a token is revoked or expires). Config entries created by the integration never stored an `id` key in their data, so any reauth attempt hit this crash.

## Cause

The reauth flow read the account identifier from `reauth_entry.data["id"]`, a key Spotify config entries never populate — the account identifier is stored as the entry's `unique_id` and the display name as its `title`.

## Remedy

Update to Home Assistant 2026.9.3 or later, which uses the config entry's title for the reauth dialog instead of the missing `id` field.

## Notes

Before the fix, deleting and recreating the Spotify integration entry was the only way to restore access; that workaround is no longer needed after updating.
