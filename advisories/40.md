# Firefly III: Subscriptions widget shows inflated "Paid" totals with multi-currency bills — fixed in 6.7.1

## Symptom

The "Subscriptions to pay" widget on the dashboard shows a wildly inflated "Paid" total — for example RD$143,000 instead of the actual ~RD$16,000 that a direct database query for the same period confirms. The log may show entries like `There is not enough information to convert USD to DOP on date ...` and `Could not find a transaction currency with code "..." in FireflyIII\Support\Amount::getTransactionCurrencyByCode`.

## Affects

Users with bills in more than one currency (for example, a native currency plus bills billed in USD) who have "Display amounts in your primary currency" enabled in Preferences, running Firefly III versions before 6.7.1.

## Cause

A currency conversion bug in how the dashboard's Subscriptions widget totals payments when amounts are being converted to the primary display currency.

## Remedy

Update to Firefly III 6.7.1 or later. If disabling "Display amounts in your primary currency" was used as a workaround, it can be re-enabled after updating.

## Notes

The underlying transaction data and per-currency totals are correct throughout; only the converted "Paid" total shown on the dashboard widget was wrong, so no data repair is needed.
