# Firefly III: Subscriptions widget shows inflated "Paid" totals with multi-currency bills — disable "display amounts in my primary currency" until 6.7.0

## Symptom

The "Subscriptions to pay" widget on the dashboard shows a wildly inflated "Paid" total — for example RD$143,000 instead of the actual ~RD$16,000 that a direct database query for the same period confirms. The log may show entries like `There is not enough information to convert USD to DOP on date ...` and `Could not find a transaction currency with code "..." in FireflyIII\Support\Amount::getTransactionCurrencyByCode`.

## Affects

Users with bills in more than one currency (for example, a native currency plus bills billed in USD) who have "Display amounts in your primary currency" enabled in Preferences. Disabling that preference makes the widget show correct per-currency totals immediately.

## Cause

A currency conversion bug in how the dashboard's Subscriptions widget totals payments when amounts are being converted to the primary display currency.

## Remedy

This is fixed, targeted for the 6.7.0 release. Until then, disable "Display amounts in your primary currency" in Preferences — the widget then shows correct totals, broken out per currency, matching the underlying transaction data.

## Notes

The underlying transaction data and per-currency totals are correct throughout; only the converted "Paid" total shown on the dashboard widget is wrong, so no data repair is needed.
