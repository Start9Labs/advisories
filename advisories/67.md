# OwnTracks Recorder: admin map is a blank blue screen on a fresh install — fixed in 1.0.4:1

## Symptom

After signing in to the OwnTracks Recorder admin web interface on a fresh install, the map is a blank blue screen. `/api/0/list` returns `{"error":"Cannot open requested directory"}` and `/api/0/last` returns `{}` instead of an empty array; the frontend then fails on `results.map` / `.filter`.

## Affects

Fresh installs of OwnTracks Recorder 1.0.4:0 before any location has ever been reported to it. Not seen once a device has recorded at least one location, and not seen on 1.0.4:1 or newer.

## Cause

The recorder's `/store` only contains `ghash/` until the first location is stored; `/store/rec` and `/store/last`, which the admin API reads from, don't exist yet.

## Remedy

Update to OwnTracks Recorder 1.0.4:1 or newer, which creates `/store/rec` and `/store/last` before the recorder daemon starts, so the admin map renders correctly even before any location has been recorded.
