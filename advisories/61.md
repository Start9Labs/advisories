# Home Assistant: EnergyZero electricity/gas prices show inflated all-in values — fixed in 2026.9.3

## Symptom

EnergyZero electricity and gas price entities show higher values than expected, because they silently switched from the market-price-with-VAT figures to all-in prices. There is no error — the entities simply report the wrong number.

## Affects

Anyone using the EnergyZero integration. The regression was introduced by an earlier library migration that left the price type unspecified, which caused the library to default to its new "all-in" price stream instead of the market-with-VAT stream the entities previously reported.

## Cause

The EnergyZero coordinator stopped explicitly requesting the market-with-VAT price type after a library migration, so it picked up the library's new default (all-in prices) instead.

## Remedy

Update to Home Assistant 2026.9.3 or later, which explicitly requests the market-with-VAT price type again and restores the original entity values.
