# Home Assistant: EnergyZero electricity/gas prices show inflated all-in values — fixed in 2026.9.3

## Symptom

EnergyZero electricity and gas price entities show higher values than expected, because they silently switched from the market-price-with-VAT figures to all-in prices. There is no error — the entities simply report the wrong number. For example, one user reported the gas sensor `sensor.energyzero_today_gas_current_hour_price` rising from an expected €1.65/m³ (incl. taxes) to €2.41/m³, and changing value mid-day rather than only at the normal 6:00 AM price update.

## Affects

Anyone using the EnergyZero integration on Home Assistant 2026.9.0, 2026.9.1, or 2026.9.2. The regression was introduced by the integration's migration from `energyzero` library version 4.0.1 to 5.0.2, which replaced the legacy gas price method with a new one defaulting to the "all-in" price stream instead of the market-with-VAT stream the entities previously reported. Both the gas and electricity price entities are affected.

## Cause

The EnergyZero coordinator stopped explicitly requesting the market-with-VAT price type after a library migration, so it picked up the library's new default (all-in prices) instead.

## Remedy

Update to Home Assistant 2026.9.3 or later, which explicitly requests the market-with-VAT price type again and restores the original entity values.

## Notes

Unconfirmed/reported workaround: until updating, the pre-regression market price excluding VAT and additional costs can still be obtained via the `energyzero.get_gas_prices` action with `incl_vat: false`, though this is not exposed as a sensor entity.
