# Jellyfin 12.0 log fills with "Failed to save similar items cache" warnings — fixed in 12.1

## Symptom

The Jellyfin log repeatedly shows warnings like:

```
[WRN] Emby.Server.Implementations.Library.SimilarItems.SimilarItemsManager: Failed to save similar items cache to "/config/cache/themoviedb-similar-movie/<hash>.json"
System.IO.IOException: The process cannot access the file '...' because it is being used by another process.
```

These recur every minute or so and fill the log.

## Affects

Jellyfin 12.0 with a Similar Items provider (e.g. TheMovieDb) enabled.

## Cause

A race condition in SimilarItemsManager: concurrent attempts to write the same similar-items cache file collide.

## Remedy

Fixed upstream in Jellyfin 12.1. Update to 12.1 or later once available for the Jellyfin service.

## Notes

Advisory #25 already covers a separate 12.0-to-12.1 issue (nested library folders). This one is distinct — log noise and a race condition writing the similar-items cache, not a library-scan display bug.
