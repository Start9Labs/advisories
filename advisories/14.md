# LND seed bootstrap fails behind a Digital Ocean StartTunnel instance

## Symptom

LND fails to find peers on startup.

## Affects

A StartTunnel instance on Digital Ocean configured as the default outbound gateway.

## Cause

Digital Ocean droplets' default DNS servers do not serve SRV records, which LND needs to bootstrap.

## Remedy

Override the DNS server for the subnet. Use 1.1.1.1, 8.8.8.8, or 8.8.4.4.

## Notes

Known since 2026-07-24.
