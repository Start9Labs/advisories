# Jellyfin 12.0: manually merged versions get split apart again on every library scan

## Symptom

After merging alternate versions of a movie or episode (either manually through the web UI or with the Merge Versions plugin), running a library scan splits them back into separate entries. This repeats on every subsequent scan — the merge does not persist.

It reproduces when the different versions (e.g. 1080p and 4K) live in separate folders or separate libraries. It does not reproduce when both versions are in the same folder within the same library, since Jellyfin auto-merges those and a rescan leaves them alone.

## Affects

Jellyfin 12.0 users with alternate versions of the same title stored in different folders or different libraries (e.g. a 4K library separate from a 1080p library), where the versions were merged manually or via a plugin rather than automatically.

## Cause

A regression in how alternate versions are grouped, introduced with the 12.0 storage changes for versions.

## Remedy

Update to Jellyfin 12.1, which includes the fix.

If you can't update yet, and your folder/file naming allows it, renaming files so the base filename (before any suffix separator) exactly matches the containing folder name — including year and provider ID — lets Jellyfin merge them automatically, and automatic merges are not affected by this bug.

## Notes

Automatic merging only works within a single library; it does not merge versions that live in separate libraries (e.g. a dedicated 4K library).
