# Cannot log in with RPC signature error on 0.4.0–0.4.0.1

## Symptom

Login fails with `RPC ERROR: Unauthorized. Invalid request signature: not valid for any identity this server recognizes (hostname, domain, or IP address); the request was likely signed for a different server identity or by an incompatible client.`

## Affects

StartOS 0.4.0 reached over Tor at its https:// address. Also StartOS 0.4.0.1 reached over LAN at a bare hostname (with the `.local` suffix omitted), when the LAN's router serves hostnames via DNS (e.g. default OpenWRT behavior). Fixed in 0.4.0.2.

## Cause

A bug in the signature auth scheme introduced in 0.4.0 makes it impossible to log in when the address used does not match a server identity StartOS recognizes, including over Tor and over LAN with a bare hostname.

## Remedy

Log in over LAN with the `.local` hostname, or a VPN gateway, instead of Tor or a bare hostname, then update to 0.4.0.2. Login works again once the update completes.

## Notes

Known since 2026-07-25.
