# ERPNext: Stock Entry submit fails with "Expiry Date Mandatory" — fixed in 15.121.3

## Symptom

Submitting a Stock Entry (Material Receipt), Purchase Receipt, or Purchase Invoice with Update Stock fails with:

> Expiry Date Mandatory: Please set Shelf Life in Days for Batched Item XXX, which is used to set Batch Expiry Date on Submit.

## Affects

Items where "Has Batch No" and "Has Expiry Date" are ticked but "Shelf Life In Days" was left at 0 — ERPNext previously allowed saving the Item in this state. If "Automatically Create New Batch" is also ticked, every auto-created batch ends up without an Expiry Date, and any inward stock transaction against that item fails at submit.

## Cause

The Item doctype did not validate that "Shelf Life In Days" is greater than zero when "Has Expiry Date" is ticked, so an invalid setup could be saved without warning and only surfaced later as a submit-time failure.

## Remedy

Update to ERPNext 15.121.3 or later, which validates this at Item save time with the message "Shelf Life In Days must be greater than zero" when "Automatically Create New Batch" is also ticked; manually created batches may still have an explicitly entered expiry date. For an Item already misconfigured, set "Shelf Life In Days" to a value greater than 0 on the Item and re-save before submitting the stock transaction.
