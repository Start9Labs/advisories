# Firefly III: mass-editing transactions with "replace tags with" keeps only the last tag — fix coming in 6.7.3

## Symptom

After selecting multiple transactions and using the mass edit action's "replace tags with" option with two or more tags, only the last tag selected is actually saved. Opening one of the edited transactions afterwards shows just the single tag instead of all the ones chosen.

## Affects

Firefly III 6.7.2 (and reported as far back as 6.6.6, though not confirmed there). Only affects mass-editing transactions to replace tags with more than one tag at once; editing a single transaction's tags normally is unaffected.

## Cause

Confirmed by a Firefly III maintainer; a fix is in progress.

## Remedy

This is a known bug, confirmed by the developer, with a fix expected in Firefly III 6.7.3. Until it ships, replace tags one at a time via the mass edit action, or edit each transaction individually to set multiple tags.
