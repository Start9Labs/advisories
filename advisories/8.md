# Clearnet certificate acquisition times out on dual-stack connections

## Symptom

A public/clearnet domain never finishes provisioning; the certificate request hangs rather than failing outright.

## Affects

Servers with both IPv4 and IPv6 available and the outbound gateway set to "Auto".

## Cause

When the box has a dual-stack connection but the default system connection is IPv4-only, outbound IPv6 hangs. Let's Encrypt prefers IPv6, so certificate acquisition times out.

## Remedy

System → Gateways → Outbound Gateway: change "Auto" to the gateway that has IPv6 support.

## Notes

Known since 2026-07-29.
