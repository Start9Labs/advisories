# Firefly III: "Clone" and "Clone and edit" buttons on the transaction list do nothing

## Symptom

Clicking "Clone" or "Clone and edit" on a transaction in the transaction list redirects to the home page without duplicating the transaction.

## Affects

Firefly III v6.7.1 and earlier, when cloning a transaction from an account's transaction list.

## Cause

A maintainer confirmed the clone action was missed in this particular view.

## Remedy

Confirmed bug, fix pending. No version is available yet to update to; check back for a Firefly III release after v6.7.1 that addresses it.

## Notes

Maintainer (JC5) acknowledged the issue on 2026-09-15 as an oversight in this specific location.
