# Firefly III: "Clone" and "Clone and edit" buttons on the transaction list do nothing

## Symptom

Clicking "Clone" or "Clone and edit" on a transaction redirects to the home page without duplicating the transaction.

## Affects

Firefly III v6.7.2 and earlier. Confirmed on an account's transaction list, the transaction detail page, and search results.

## Cause

A maintainer confirmed the clone action was missed in these views.

## Remedy

Confirmed bug, fix pending. No version is available yet to update to; check back for a Firefly III release after v6.7.2 that addresses it.

## Notes

Maintainer (JC5) acknowledged the issue on 2026-09-15 as an oversight, initially believed limited to one view but confirmed on 2026-09-16 to also affect the transaction detail page and search results. Issue has been labeled "fixed" pending a future release.
