# StartOS server unreachable via mDNS after choosing a long name at setup — fix ships in 0.4.0.2

## Symptom

After setup, the server cannot be reached via its `.local` mDNS address. This happens when a long server name was chosen during setup — for example a 37-character name like `chinapure1071balckdiskcontrollertest` failed, while a 15-character name worked fine.

## Affects

Servers whose name (chosen at setup) is longer than 32 characters.

## Cause

Server names longer than 32 characters are not reliably resolvable via mDNS/Avahi, but StartOS did not enforce or warn about any limit when the name was chosen.

## Remedy

Update to 0.4.0.2, which caps server names at 32 characters going forward and automatically repairs any existing longer name during update, restore or transfer. Until then, choose (or change) the server name to 32 characters or fewer.

## Notes

Reported against 0.4.0.1; fix confirmed by a maintainer on master, shipping in 0.4.0.2.
