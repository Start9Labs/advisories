# ERPNext: fully billed Sales Orders reappear in "Get Items From" and add no items — fixed in 15.121.3

## Symptom

After updating to 16.34.2, Sales Orders that are already fully billed and fully delivered show up again when using "Get Items From → Sales Order" on a Sales Invoice, or via the Create → Sales Invoice button on the Sales Order form, even though nothing is left to bill. Selecting one of these orders adds no items — the dialog closes and the invoice stays empty.

## Affects

Users with "Over Billing Allowance" set to a nonzero value in Accounts Settings. Setting the allowance to 0 makes the fully-billed orders disappear from the list again, but that also disables the allowance for legitimate cases.

## Cause

A regression introduced by a change to the over-billing allowance logic (frappe/erpnext#58820), which stopped correctly excluding fully billed and delivered Sales Orders when an allowance is configured.

## Remedy

Update to ERPNext 15.121.3 or later, which resolves this issue.

## Notes

Reported against 16.34.2/16.43.2; the fix shipped in the 15.121.3 release line.
