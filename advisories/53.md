# ERPNext: "Transfer Materials" from a Job Card's Workstation menu throws a server error — fixed in 15.121.3

## Symptom

Opening a Workstation, using the three-dot menu next to a Job Card, and selecting "Transfer Materials" raises a server-side error instead of opening or creating the material transfer transaction. The error text is: `'>=' not supported between instances of 'NoneType' and 'NoneType'`.

## Affects

Manufacturing users on ERPNext versions before 15.121.3, specifically when the Job Card's Raw Material table has no records. This occurs with a Work Order whose "Transfer Material Against" is set to Work Order and "Track Semi-Finished Goods" disabled, when the Job Card generated from it has an empty Raw Materials table.

## Cause

The Transfer Materials action did not handle an empty Raw Material table correctly, and raised a server error instead of proceeding.

## Remedy

Update to ERPNext 15.121.3 or later, where this is fixed.

## Notes

A prior report of the same symptom (#55214) was closed as fixed but the error recurred on later versions; this is the confirmed fix version. A workaround used before the fix was to add an empty row to the Raw Material table before transferring materials, but this is no longer necessary after updating.
