# FileBrowser Quantum: direct download links bypass a share's password

## Symptom

A folder or file is shared with a password, but the direct download link (or the downloaded zip) can be accessed by anyone with the link, without ever being prompted for the password. Separately, the folder name of a password-protected share may be visible in the sidebar before the password is entered.

## Affects

Anyone using FileBrowser Quantum's password-protected share feature to restrict access, on versions before the fix. Browsing a share still correctly prompts for the password — only the direct download link/token bypasses it.

## Cause

The download link embedded a token that granted direct download access without checking the share's password.

## Remedy

Update to the FileBrowser Quantum beta version that includes this fix (2.63.9:0 or newer in the Start9 Beta Registry). After updating, downloading from the share UI requires entering the password; a passwordless download link is still possible but only as a short-lived token (up to 24 hours) generated by the share owner or an admin, and generating that token itself requires the password.

## Do not

- Do not treat the password as protecting downloads on unpatched versions — it only protects browsing.

## Notes

Until updated, treat any previously shared direct download link for a password-protected share as unprotected, and consider it compromised if it may have been shared with anyone who should not have access.
