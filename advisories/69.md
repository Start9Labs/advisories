# LND: "Unlock Wallet" task button does nothing under Cold Storage Mode — reinstall 0.21.3-beta:3 from alpha

## Symptom

After enabling Cold Storage Mode and starting LND, an "Unlock Wallet" task appears but its button does nothing — no password form opens, and the only option is to dismiss the task. This happens on both an upgrade to 0.21.3-beta:3 and a fresh install of it.

## Affects

LND users running Cold Storage Mode on package version 0.21.3-beta:3 installed before the fix below landed. A locked wallet keeps the service showing `starting` rather than `running`, and the task's button only worked while the service showed `running`, so it could never fire.

## Cause

The Unlock Wallet task's button was wired to an `only-running` UI action, which only runs while the service status is `running`. Under Cold Storage Mode a locked wallet holds the service at `starting`, so the button never fired.

## Remedy

Fixed in place on the Start9 Alpha Registry under the same version, `0.21.3-beta:3` — StartOS will not show this as an update since the version number is unchanged. Reinstall LND from the alpha registry to pick up the fix; data and channels are kept across the reinstall. After it starts, the Unlock Wallet task's button will open the password form while the service is still `starting`.

## Notes

Only the alpha registry carries the fixed build under this version tag; the Beta and Start9 registries still list 0.21.3-beta:3 as shipped prior to the fix, so check which registry the install came from.
