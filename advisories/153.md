# Open WebUI: chat title stays "New Chat" until reload when title generation is off

## Symptom

With title generation turned off (either per-user or by the admin), a new chat keeps showing "New Chat" in the header and browser tab instead of the actual title, until the page is reloaded. In a note's chat panel, the whole model reply can show up as the title instead.

## Affects

Anyone using Open WebUI with title auto-generation disabled. The sidebar is not affected, since it reloads titles from the database; this only affects the live header/tab title and note chat panels.

## Cause

The chat is saved with the first user message as its title, but the live `chat:title` event sent the assistant message instead — which is still empty at that point when title generation is off.

## Remedy

This is fixed upstream, but the fix has not yet reached a released version. It will be available once a StartOS release containing it ships. Until then, reload the page to see the correct title.

## Notes

Unconfirmed whether this affects only new chats or also renames of existing ones; the fix (open-webui/open-webui#31355) makes the fallback branch send the just-saved title, matching what the generated-title branch already does.
