# Jellyfin 12.0: migration gets stuck in an infinite loop removing duplicate media — fixed in 12.1

## Symptom

After updating to Jellyfin 12.0, the web UI stays stuck on "Perform migration `20260113120000_MigrateLinkedChildren`" and never finishes. The server logs repeat the same lines indefinitely, for example:

```
Removing alternate version with wrong type "Video", expected "Movie": "..."
Removing item, Type: "Video", Name: "...", Path: "...", Id: ...
```

## Affects

Jellyfin 12.0 instances with libraries containing duplicate or alternate-version media files (e.g. multiple versions of the same movie) that trigger the `MigrateLinkedChildren` migration.

## Remedy

Update to Jellyfin 12.1, which includes the fix for this migration loop.

## Notes

This is a distinct issue from the general 12.0 migration/crash problems already tracked (see advisories 24 and 25), specific to libraries with alternate/duplicate media versions.
